Pico ⚡

Local-first image compressor. No cloud, no limits, 100% private.

npm i -g pico-img MIT License Node ≥ 18 Windows · macOS · Linux zero telemetry

Why Pico

🔒 100% LocalImages are compressed on your machine via Sharp (libvips) — nothing is ever uploaded.
🧬 Best codecsmozjpeg for JPG, level-9 palette PNG, effort-tuned WebP & AVIF.
🎚️ Quality 10–100Real-time slider from tiny files to lossless-ish fidelity.
🔌 CLI + REST APIScriptable: POST /api/compress returns sizes & savings as JSON.
📊 Live resultsBefore/after sizes and −XX% savings badges with instant downloads.
🧹 Auto cleanupTemp uploads are deleted automatically — zero disk bloat.
